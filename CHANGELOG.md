# Changelog

## 1.0.0 — 2025-10-07

- Initial release of the Logitech GHub Macro Controller Script
- Supports mouse and keyboard G-keys
- Per-key modes: toggle and hold
- Dynamic abort keys
- Configurable debounce for press events

## 0.9.0 — 2025-08-12

- Added ghub_macro_browser.py for bulk macro editing
- Sequence component editor with drag-and-drop reorder
- G-key assignment tools for memory profiles
